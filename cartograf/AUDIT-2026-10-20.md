# AUDIT — cartograf (2026-10-20)

_Second hardening pass. This is a corrections audit, not a new strategy. It fixes
three defects that changed the headline numbers and adds the statistics the
claim needed. Reproduce with the commands at the bottom._

## 1. Turnover denominator was too large

`_build()`, `_carry_leg()` and `network_sleeves.build()` divided the turnover
sum by the full price-panel length. The panel starts in 2003; the targets start
in 2008. The turnover sum covers only the traded window, so the denominator was
~27% too large.

| Sleeve | Reported before | Corrected |
|---|---:|---:|
| trend | 17.4× | **22.1×** |
| xsmom | 8.9× | **11.3×** |
| value | 5.1× | **6.4×** |
| BAB | 3.6× | **3.6×** |
| VRP/SVXY | 0.6× | **0.8×** |

The net P&L was already correct (costs are charged per trade); only the reported
turnover — and the cost drag a reader infers from it — was understated.

## 2. Month-end alignment: the VRP and core series were gappy

`vrp_monthly()` aligned SPY realised vol (calendar month-end) to the trading-day
month-end with an exact-timestamp `reindex`. Every month whose last calendar
day was a weekend or holiday silently became NaN, and `dropna()` removed it.
The VRP sample was **200 months instead of 285**. The same exact-timestamp
alignment affected the core book and the SVXY proxy.

**Fix.** Align by `to_period("M")` everywhere: RV to `me`, the monthly core
legs to each other, SVXY to `df.index`, and the monthly price benchmark to the
VRP index.

Effect:

| Quantity | Before | After |
|---|---:|---:|
| VRP months | 200 | **285** |
| mean implied vol | 19.0 | **19.1** |
| mean realised vol | 15.6 | **15.3** |
| mean P&L (vol points/month) | +1.83 | **+2.40** |
| months implied > realised | 81.5% | **83.5%** |
| gated VRP Sharpe | 0.90 | **1.18** |
| gated VRP CAGR / vol / MaxDD | 9.3% / 10.7% / −27.0% | **14.1% / 11.9% / −26.8%** |
| core (trend+BAB+gated VRP) Sharpe | 0.66 | **0.85** |
| core CAGR / vol / MaxDD | 6.6% / 10.7% / −16.7% | **10.3% / 12.5% / −28.1%** |
| 60/40 + 30% core, monthly | — | **Sharpe 1.24, MaxDD −11.6%** |

The old B result was not wrong because the premium is weak; it was wrong because
a third of the months were missing. The corrected B is strong, but the caveats
are unchanged: no 2008 test (VIX3M starts 2009-09), one regime, 5 bps/month is
optimistic for a variance position, and the gate failed February 2018.

## 3. BAB: the mask was not enough

The live-name mask removed pre-inception names, but beta and vol were still
computed on the zero-filled return panel. For the first 252 days after listing,
zeros biased beta toward 0 and vol downward, producing a high BAB score. The
new code estimates beta and vol from `prices().pct_change()` with
`min_periods=252` / `63`; `live_mask()` now also requires 20 observations and a
print in the last 5 days.

Effect: BAB Sharpe **0.101 → −0.083**; CAGR +0.5% → **−1.6%**; MaxDD −38.4% →
**−46.8%**. The verdict is now stronger: the ETF BAB proxy does not survive. The
core still includes BAB because it was pre-specified; a trend+VRP core (a new
trial, not the published core) scores Sharpe 1.02 but with a −39.7% drawdown, so
dropping BAB is not a free improvement.

## 4. Statistics

- Sortino now uses downside deviation `sqrt(mean(min(r,0)^2))`, not the standard
  deviation of negative returns. It was understating Sortino.
- WorstYear/BestYear now exclude the partial 2026.
- The DSR is reported on the **claim** (60/40 + 30% core), not only on the core
  sleeve. A moving-block bootstrap (2,000 draws, 6-month blocks) gives the
  sampling interval.

| Claim | Sharpe | 95% bootstrap CI | DSR (23 trials) |
|---|---:|---:|---:|
| 60/40 daily + 30% core | 1.26 | 0.82 – 1.84 | **0.986** |
| 60/40 monthly + 30% core | 1.24 | 0.80 – 1.82 | **0.984** |
| 60/40 + 30% gated VRP | 1.35 | 0.84 – 2.05 | **0.988** |

For comparison, the core sleeve's own DSR is still ~0.50: the sleeve is not
significant after deflation, the overlay is. That is the right way to read the
product.

## 5. Benchmark convention

A monthly-rebalanced 60/40 (SPY/IEF, no rebalancing costs) scores Sharpe **0.973**
over 2003–2026, versus **0.77** for the daily-rebalanced series used in the body.
The core overlay still improves it (1.24–1.26), but the size of the improvement
depends on the convention. Both are now in `metrics.json`; the daily series is
kept for continuity.

## What not to over-trust

- The VRP result is one regime (2009-11+); there is no 2008 observation for B.
- 5 bps/month is optimistic for a variance position; stress it.
- Network momentum is unchanged: +0.09 standalone, +0.03 portfolio, one
  specification, inside the noise.
- Carry is unchanged and still does not earn its place on spot ETFs.
- The ETF universe is still today's list; the cross-sections are upward-biased.
- The core weights are equal and pre-specified; this is not an optimiser.
