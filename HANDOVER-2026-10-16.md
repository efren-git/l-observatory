## Pitfalls learned (do not rediscover these)

- Paths contain apostrophes (`l'Observatori`, `nit_d'alba`) — **double-quote every occurrence** in shell.
- **FRED:** use the **default** User-Agent (custom UAs get throttled). `fredgraph.csv?id=SERIES` works, no key.
- **Yahoo:** raw HTTP gets 429s — must use the `yfinance` client.
- **CBOE:** index histories are free at `cdn.cboe.com/api/global/us_indices/daily_prices/`; VIX *futures*
  settlements return **403 AccessDenied**.
- **arXiv API:** must use **https** (the http endpoint 301s to nothing).
- **VIX3M only starts 2009-09-18** — so the gated VRP has no 2008 test.
- **SVXY changed leverage in Feb 2018** — a dirty short-vol proxy.
- ICE BofA credit yields on FRED go back only ~3 years (licensing) — unusable historically.
